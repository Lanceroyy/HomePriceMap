# Search Console URL Hygiene Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop the site from internally advertising duplicate homepage and query-string map URLs while preserving the intended clean map URL and every indexable county profile.

**Architecture:** Treat `https://homepricemap.us/`, `counties.html`, and the static `counties/*.html` profiles as the indexable URLs. Legacy `counties.html?fips=...` URLs remain backward-compatible map-state links, but source templates and checked-in static pages must link only to canonical URLs or fragment state. A small standard-library regression test scans the source-of-truth files and sitemap.

**Tech Stack:** Static HTML, vanilla JavaScript, Python 3 standard library, GitHub Pages.

**Spec:** The two Search Console Coverage Drilldown exports dated 2026-09-16.

## Global Constraints

- Do not try to index query-string map-state URLs; they duplicate `counties.html`.
- Do not hand-edit generated files under `counties/`, `cities/`, or `states/`.
- Keep legacy query-string links functional through the existing JavaScript compatibility path.
- `state_pages_builder.py` remains the final sitemap writer in the deployment workflow.
- Do not add robots.txt blocks for query parameters because that would obstruct canonical processing.
